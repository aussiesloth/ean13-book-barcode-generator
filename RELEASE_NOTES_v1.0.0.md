# EAN-13 Book Barcode Generator v1.0.0

Initial public release of a small, offline EAN-13 barcode generator aimed at authors and independent publishers.

## Highlights

- Single-file browser app: no installation, account, external library or internet connection required after download.
- ISBN-focused `978` / `979` validation.
- Automatic EAN-13 check-digit calculation and validation.
- Vector SVG export for print-cover artwork.
- High-resolution PNG export with crisp integer-pixel modules.
- White or transparent backgrounds, with transparent-output warning.
- GS1-oriented sizing and quiet zones.
- Optional dependency-free Python/Tkinter desktop version.
- Example SVG and PNG output.

For ordinary book-cover work, use the standalone HTML version and export SVG on a white background at 100% unless your printer or distributor specifies otherwise.

See `README.md` and `docs/STANDARDS_NOTES.md` before production use.
