# Suggested GitHub setup

## Repository name

`ean13-book-barcode-generator`

## Description

Offline, dependency-free EAN-13/ISBN-13 barcode generator for print book covers. Export vector SVG or high-resolution PNG entirely in your browser.

## Suggested topics

`ean13` `isbn13` `barcode` `book-publishing` `self-publishing` `publishing-tools` `svg` `png` `offline` `javascript` `python` `kdp`

## Visibility

Public.

## Default branch

`main`

## GitHub Pages

Enable Pages from the `main` branch and repository root. The root `index.html` is already the complete application.

## Suggested About settings

- Website: use the GitHub Pages URL after Pages is enabled.
- Releases: enabled.
- Issues: enabled if you want bug reports and feature requests.
- Discussions: optional; probably unnecessary for the first release.

## First release

Tag: `v1.0.0`

Title: `EAN-13 Book Barcode Generator v1.0.0`

Suggested release notes:

> Initial public release of the EAN-13 Book Barcode Generator — a small, offline tool aimed at authors and independent publishers. The recommended version is a single HTML file that runs locally in a modern browser with no installation, account, external library or internet connection required after download. It validates ISBN-13/EAN-13 values, calculates check digits, and exports vector SVG or high-resolution PNG artwork.
>
> Also included is an optional dependency-free Python/Tkinter desktop version.
>
> See the README for print sizing, quiet-zone and transparent-background guidance.

Attach `EAN13_Book_Barcode_Generator_v1.0.0.zip` to the release.
